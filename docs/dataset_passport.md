# Паспорт датасета PM2.5 Бишкека

Период контрольной выгрузки с 7 по 13 сентября 2026 года по местному времени Asia/Bishkek. Единица измерения µg/m³.

| Источник | Назначение |
|---|---|
| data/sensors_history.csv | 646 исходных измерений из OpenAQ AWS Archive, датчики 15138119 и 15138111. |
| data/locations_dictionary.csv | 4 станции OpenAQ с координатами и идентификаторами. Справочник загружается целиком. |
| OpenAQ API /v3/sensors/{sensor_id}/hours | Почасовые значения с датчиков 15138127 и 15138348. Задача запрашивает данные за ds. |
| data/api_hourly_real.csv | Контрольный снимок из живого API на 209 строк за неделю. Используется для сверки. |

Ссылки на архив, контрольные суммы, провайдеры и лицензии записаны в data/openaq_sources.json. Пропуски отражают отсутствие наблюдения. Утверждение датасета преподавателем фиксируется отдельно.
